A one-page plan to make money with AI agents, for a bounty on
[make.fun](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138).

## The plan

> Day 1: list 50 clinics/salons with no online booking (Google Maps). Email each: $199 AI booking chatbot, built in 1 day, n8n free tier. $100: domain + Apollo credits. Close 3 by day 10 = $597. Repeat daily, upsell $49/mo. Drop leads silent 3 days; no build before $99 deposit.

In short: find local clinics and salons that still take bookings by phone,
offer them a $199 AI booking chatbot built in a day on the n8n free tier,
spend $100 on a domain and Apollo credits, close 3 clients by day 10 for
$597, repeat daily, upsell $49/month, drop leads that go silent for 3 days,
and never build before a $99 deposit lands.

## This repository

- `main.ts` — the entry program (Node 22, standard library only, no
  network): it writes the plan above to `/output/entry.txt`. Run it the way
  the grader does:

  ```sh
  node main.ts
  ```
